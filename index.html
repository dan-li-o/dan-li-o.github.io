About

Think like a writer; design like an artist; prototype like an engineer.

I move between essays, facilitation, and code. Sometimes that looks like building a bespoke tool for a founder, other times it means translating a research program into a public narrative. The throughline is clarity.

When a problem feels messy, I map it, name the tensions, and design light-touch systems that invite people in. Clarity is a craft, not a constraint.
